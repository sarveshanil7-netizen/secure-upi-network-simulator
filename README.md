# Secure UPI Network Simulator

## Overview
Secure UPI Network Simulator is a group project that demonstrates secure digital payment processing through a simulated network. It focuses on transaction security, data encryption, and reliable payment handling.

## Features
- Secure payment data transmission
- Encryption and data integrity
- Transaction validation
- Duplicate transaction prevention
- Simulated network-based payment processing

## Technologies Used
- Java
- Spring Boot
- Cryptography
- Web Technologies

## Disclaimer
This project is developed for educational and demonstration purposes only. It is not connected to the real UPI network and should not be used for actual financial transactions.

## Team Project
Developed collaboratively as an academic group project.
